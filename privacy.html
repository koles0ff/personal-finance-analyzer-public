Privacy Policy

Last updated: November 5, 2026

1. Purpose

Personal Finance Analyzer is a private, non-commercial application developed for analyzing the account owner's financial transactions and spending patterns.

2. Information Accessed

With explicit authorization, the application may access account identifiers, balances, transaction dates, amounts, currencies, and transaction descriptions.

3. Banking Integration

Bank account information is accessed through Enable Banking's Open Banking API. The application does not collect or store online banking passwords.

4. Data Processing and Storage

Financial information may be processed and stored locally for personal analytics. Data is not sold or provided to advertisers. Optional AI-assisted analysis may involve sending selected transaction information to an external AI service when explicitly enabled.

5. Data Retention and Deletion

Stored financial information is retained only as needed for personal analysis. The account owner may delete locally stored information and revoke banking access through the relevant authorization mechanisms.

6. Security

The application is intended for private use. API credentials and financial records are not published in the public source code repository.

7. Contact

For privacy inquiries, contact the application owner using the data protection email provided during Enable Banking application registration.
